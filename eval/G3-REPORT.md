# G3 — Perception evaluation report (Sprint 3)

Generated by `eval/run_eval.py` (this repo) on top of the S1/S2 datasets
and artifacts. Every number below is reproducible from the commands in
[Commands](#commands); generated tables land in `processed/`
(`g3_metrics.csv` tidy long format, `g3_metrics.md` human tables,
`g3_report.json` full report incl. failure-mining records).

## What was evaluated

| stage | population | split discipline |
|---|---|---|
| classifier v0 | african_wildlife **test split only** — the trainer's own 375-crop held-out cache (`classifier_crops_v0.json`, split `test`) | 6-check integrity gate run FIRST (see below); crop windows independently recomputed from the YOLO labels — 375/375 integer-exact |
| detection (MDv6) | the S2 800-image deterministic evaluation sample (seed 42): 400 AW-with-GT / 300 Missouri-with-GT / 100 Missouri-empty | split-agnostic: MDv6 is pretrained, nothing here was trained on these images; the AW stratum spans train/val/test — documented, no leak vector |
| sequence logic | Missouri's 100 GT sequences (1,276 frames) + AW **test-split** bursts (227 images) | species selected-vs-all restricted to pure-test bursts (bursts whose every frame is test) |
| motion gate | full manifest — 26,177 frames, 48 cameras | no labels involved |

Held-out integrity (classifier): the evaluated crop set must be exactly
the trainer's test index — split membership, unique ids, vocabulary,
count match vs `classifier_v0_meta.json` (375), every source image inside
the manifest's test split, and zero overlap with train/val source images.
All 6 checks pass; the harness raises on any violation and the runner
refuses to produce classifier numbers otherwise.

## Day/night split — definition and honesty

G3's day/night split is a **content-based IR flag**: mean HSV saturation
< 25.0 on the ≤1024 px working decode (night camera-trap frames are
infrared grayscale, saturation ≈ 0; Missouri's distribution is sharply
bimodal, p50 0.8 vs p95 122, so the exact threshold sits in a wide moat).

The manifest's `is_night` column is a **synthetic random assignment**
(`etl/synthetic.py`, night_weight 0.45) — its agreement with the content
flag is chance level (0.449 missouri / 0.516 african_wildlife over the
full manifest; 0.415 / 0.49 on the S2 det sample). It is never used to
split a G3 number; it is reported only as this agreement statistic.

Coverage honesty: the AW test split is almost entirely day — **5 of 375
test crops are IR-night** — so the AW night classifier cell exists but is
too small to read (n=5, reported for completeness, explicitly NOT a
night-performance claim). Missouri is 71% IR frames, so the night story
is carried by Missouri detection/sequence numbers, where n is large.

## Failure catalog

`eval/failures/CATALOG.md` — 7 cases with annotated images under
`eval/failures/images/`: two missed detections (day close-up
fragmentation; night edge-hugging blind spot), two species confusions
(smallest-crop upsampling; frame-edge truncation), the closed-set OOV
case (Missouri roe deer → "rhino"), one sequence-selection failure, one
motion-gate false positive with the exact replayed MOG2 mask. Each case
carries its measured numbers, a one-paragraph diagnosis, and the pick
rule + ids that reproduce it.

## Caveats

1. CPU-only environment; timings are not GPU-comparable and no batching
   exists to degrade.
2. Classifier top-5 is degenerate (4 classes); night crops n=5 — too
   small for a macro reading; both stated rather than hidden.
3. Missouri carries no classifier metrics (species disjoint from v0's
   vocabulary — closed-set OOV, demonstrated as failure case 5); CCT20
   is metadata-only in this repo (images never downloaded) and excluded
   from every stage.
4. Detection n = the S2 sample (800 images), not the full datasets; the
   AW det stratum spans train/val/test images (pretrained detector, no
   leak vector — documented).
5. Missouri sequence recall is box-level: a selected frame without a GT
   box counts as not-matched even when the animal is visible —
   Missouri's GT annotates a subset of frames per sequence, so
   selected-recall there is a lower bound.
6. The motion pass applies CLAHE on the content-IR flag; S1's bench used
   the synthetic `is_night`, so trigger rates are not directly
   comparable to S1 numbers.
7. Species selected-vs-all uses pure-test AW bursts only (mixed-split
   bursts excluded from both sides); n differs between the two rows and
   is printed with each.

## G3 verdict

**G3: closed.** All seven deliverables landed: the harness
(`eval/run_eval.py`, split-integrity gate first, all four stages
reproducible from two commands), the deterministic metrics table
(`processed/g3_metrics.csv` / `.md` — micro+macro, day/night via the
content-IR flag with the synthetic `is_night` agreement published),
detection recall/FP-per-image at the operating threshold plus a 3-point
conf sweep, the sequence ladder (trigger observed 0.8884; union→gated→
selected 0.9349→0.8093→0.7535 over 215 GT sequences), a 7-case failure
catalog with annotated images and reproducible keys, this report, and
53 passing offline tests (30 eval + 23 pipeline).

What the evaluation found, in one paragraph: the deployed perception
stack is honest at the image level (classifier 0.9867 on its held-out
split, reproduced bit-tight against the trainer's torch reference;
detector 0.7945 recall at deploy conf) and the sequence layer costs
little on top of it (selection loss 5.6% of GT sequences; selected-
frame species accuracy 1.0 on n=75 vs 0.993 all-frames). The failure
catalog's two detector mechanisms — close-up fragmentation (day) and
edge-hugging small night targets — plus the MOG2 burst-start spike are
the concrete inputs for the next sprint; none of them is fixable by
threshold tuning alone, which is exactly the kind of statement this
gate existed to make.

Scope honesty: the numbers above are measured on the populations
stated in [What was evaluated](#what-was-evaluated) — the trainer's
375-crop AW test cache, the S2 800-image sample, 100 Missouri GT
sequences + 115 AW test bursts, and the full 26,177-frame manifest.
Small cells are labeled in place (AW night n=5 crops / 12 boxes;
missouri|day seq n=27) rather than aggregated away.
