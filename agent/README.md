# agent — S4 triage agent (Gate G4)

A Bedrock-style tool-calling agent over the perception output of the
earlier sprints: for each detection batch it consults four context tools
(`get_detection`, `query_zone`, `query_hour`, `query_history`) and emits
one conditional action with a complete, byte-deterministic trace.
Offline-first: the default backend is a deterministic rules
implementation behind a documented adapter interface; the Bedrock
adapter is a stub that refuses to run without real credentials.

Full sprint verdict with evidence: `agent/G4-REPORT.md`. Kill-switch B
corpus comparison: `agent/artifacts/corpus_comparison.{json,md}`. The
demo: `agent/demo/` (fixture, runner, committed traces + transcript).

## Layout

| path | what |
|---|---|
| `tools.py` | tool registry + `ContextStore` (events/zones in memory), curfew math, `ToolError` |
| `adapters.py` | the adapter protocol; `RulesAdapter` (default, `rules-v1`) with the decision table; `BedrockAdapter` (documented stub) |
| `loop.py` | the transport: runs an adapter to a `Decision`, records every step, budget + error safety |
| `actions.py` | action-record builders with their invariants (approval flags, person → blur) |
| `policy.py` | every threshold with provenance; simulated-context tags |
| `trace.py` | trace schema + canonical JSON + `trace_id` (sha256 over the trace minus the id — no wall clock anywhere) |
| `baseline.py` | `rules-only-v1` — the kill-switch B baseline: same perception thresholds, NO context |
| `scenario.py` | pure event/zone assembly (stdlib-only; unit-tested) |
| `runtime.py` | the heavy side: corpus loaders (batches × manifest × G3 IR flags) and the LIVE pass-2 re-analysis (lazy cv2/pyarrow/wildlife_monitor imports) |
| `run_corpus.py` | both lanes over the 200-event corpus → committed comparison artifact |
| `demo/` | showcase fixture + runner + committed artifacts (`TRANSCRIPT.md`, `traces/*.json`) |
| `tests/` | 79 offline tests (stdlib + pytest only) |

## Running

    # offline tests (the core is stdlib-only)
    ../wildlife-monitor/.venv/bin/python -m pytest agent/tests -q

    # kill-switch B corpus comparison (pyarrow; writes the committed artifact)
    ../wildlife-monitor/.venv/bin/python -m agent.run_corpus

    # the G4 demo (loads the ONNX detector for the live pass-2, seconds)
    ../wildlife-monitor/.venv/bin/python -m agent.demo.run_demo

Full suite from the repo root:

    ../wildlife-monitor/.venv/bin/python -m pytest eval/tests pipeline/tests agent/tests -q   # 132

Scratch traces land in `processed/` (gitignored, regenerated by the
runners). Committed artifacts under `agent/artifacts/` and
`agent/demo/artifacts/` reproduce byte-identically.

## What is real and what is simulated

Real: every perception payload (S2/E2E union `cv2.dnn` detections), the
G3 content-IR night flags, and the pass-2 re-analysis pixels (live
MDv6 forward with the motion gate's grayscale-CLAHE recipe).

Simulated (tagged in every trace): the zone layer (the ETL's per-camera
`zone_restricted` flag + this sprint's fixed 18:00–06:00 restricted
window) and the clock (the manifest's `camera_ts` is a synthetic
uniform assignment — corpus events carry `clock_source:
manifest-synthetic` with a fixed per-dataset UTC offset; demo scenarios
that pin a context carry `pinned-demo`). Night is ALWAYS the content-IR
flag, never the synthetic `is_night`.

Framing held everywhere: presence of people in a restricted zone/hour
routes to a human approval queue or escalation — the product approves,
never accuses; every action on person evidence carries
`face_blur_required` and `approval_required`.
